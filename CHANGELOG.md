# 3.2.0

- Run Now checks one batch for 30 seconds, organizes ready items once and stops.
- Cancel run during the readiness check; completion reports moved, skipped and failed items.
- Files arriving after the first check are left for a later run.
- Start automatic is a separate option. Pausing, cancellation, errors and one-time completion clear scan timers.
- Run Now turns automatic mode off and leaves the app paused when finished.
- Keeps the existing routing, exclusions, intact folders, collision protection and activity logging.

# 3.1.0

- Dedicated Import & export page and import during first-time setup.
- Import review with group names/counts and confirmation before replacement.
- Portable validation and readable errors for invalid, oversized or unsupported files.
- Exports include the current draft and only portable sorting fields.
- Watch/output locations, exclusions, protections, startup preference and history stay local.
- Optional original sorting rules included as a separate JSON file.
- Version-1 exports remain compatible; imports and new launches start paused.
